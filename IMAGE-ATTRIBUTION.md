### Attribution Implementation

The footer component automatically displays:
> "Images courtesy of Unsplash"

This provides proper credit to the Unsplash community and photographers.

### For Production Use

When using this template for your portfolio:

1. **Keep Attribution**: The footer attribution should remain to credit Unsplash
2. **Replace Images**: Consider replacing with your own project screenshots
3. **Profile Photo**: Replace the demo profile image with your own professional photo
4. **Project Images**: Use actual screenshots of your completed projects

### Alternative Image Sources

If you prefer other image sources:
- **Your Own Work**: Screenshots of your actual projects
- **Pexels**: Another free stock photo platform
- **Custom Graphics**: Design custom placeholder graphics
- **Client Work**: With permission, use images from client projects

### Technical Notes

- All images are optimized for web (800x600px for projects, 800px width for profile)
- Images are loaded from CDN for fast performance
- Lazy loading is implemented for better user experience
- Responsive image sizing is handled by CSS

The attribution footer ensures compliance with best practices while giving credit to the photography community.
